# Atividade Extra - Pré-processamento de Dados (Oficina Mecânica)

Repositório estruturado para a resolução da atividade extra de pré-processamento de dados utilizando Python e bibliotecas de ciência de dados.

## 📁 Arquivos do Projeto

- **`Atividade Extra 01102026.csv`**: Arquivo de dados bruto da oficina mecânica contendo as inconsistências propostas para fins didáticos.
- **`main.py`** (ou seu script principal): Script contendo todo o pipeline de tratamento, limpeza, transformação e exportação dos dados.
- **`base_oficina_preprocessada.csv`**: Base de dados final gerada após todas as etapas de pré-processamento.

## 🚀 Como Executar

Certifique-se de ter o Python 3 e as bibliotecas necessárias instaladas (`pandas`, `numpy`, `scikit-learn`). 

No seu terminal, execute o script principal:
```bash
python main.py
```

## 🛠️ Tecnologias Utilizadas
- Python 3
- Pandas e NumPy (Manipulação e tratamento de dados)
- Scikit-Learn (Escalonamento, codificação e divisão de bases)
